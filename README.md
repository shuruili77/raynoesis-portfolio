# raynoesis portfolio

Static, bilingual portfolio for raynoesis: Chinese-inspired architecture, gardens, interiors and vessels. English is the default, with a Chinese language toggle.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8765 --bind 127.0.0.1` from this directory and visit `http://127.0.0.1:8765/`.

## Repository scope

This repository contains the website and optimized showcase images only. It does not contain Unity packages, Blender projects, source textures, game-development assets or private provenance records.

All seven asset projects are local technical candidates. They are not currently listed or approved on the Unity Asset Store. The portfolio describes actual tested scope and limitations. Images are Unity renders; the creative workflow is AI-assisted, including GPT.
